# FinanCont

Sistema de gestão financeira desenvolvido como projeto acadêmico com HTML, CSS e JavaScript puro.

## Descrição

O FinanCont tem como proposta reunir em um só lugar recursos para organizar movimentações financeiras e acompanhar contas pessoais. O projeto está em desenvolvimento; as funcionalidades abaixo estão planejadas.

## Objetivo

Aplicar conhecimentos de desenvolvimento web na criação de uma ferramenta simples e acessível para registrar receitas e despesas, acompanhar compromissos financeiros e visualizar informações de forma organizada.

## Acesso ao projeto

Acesse a versão publicada: [financont.vercel.app](https://financont.vercel.app).

## Funcionalidades planejadas

- **Login:** acesso à área do usuário.
- **Dashboard:** resumo da situação financeira.
- **Lançamentos:** registro e consulta de receitas e despesas.
- **Contas a pagar e a receber:** acompanhamento de vencimentos e valores.
- **Relatórios:** visualização consolidada das movimentações.

## Como rodar

Não é necessário instalar dependências. Abra o arquivo `index.html` no navegador.
